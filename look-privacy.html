"이거 좀 봐 줄래" 개인정보처리방침

시행일: 2026년 11월 10일

주식회사 위리드코퍼레이션(이하 "회사")은 하루효도 "이거 좀 봐 줄래" 앱(이하 "앱")에서 이용자의 개인정보를 다음과 같이 처리합니다.

1. 처리하는 개인정보와 목적

항목목적보관 기간
이름(이용자가 적은 호칭, 예: 엄마·민수)연결된 가족에게 누구인지 보여 주기[모든 기록 지우기] 또는 앱 삭제 후 1년간 이용이 없을 때까지
기기 식별값(무작위 ID), 푸시 알림 토큰가족 연결, 도움 요청 알림(벨) 보내기위와 같음
가족 연결 정보(누구와 연결됐는지, 연결 일시)승인한 가족만 도움 요청을 받게 하기연결을 끊거나 기록을 지울 때까지
도움 기록(시작·끝 시각, 받은 가족, 해결 여부)기록 화면 보여 주기, 서비스 개선1년
아이폰 대기 신청 여부아이폰용 출시 판단출시 안내 후 삭제

회사는 이름 외의 실명, 전화번호, 이메일, 위치, 연락처를 수집하지 않습니다.

2. 화면·음성은 저장하지 않습니다

  • 부모님이 [시작]을 누르면 부모님 휴대폰 화면과 음성이 연결된 가족의 휴대폰으로 실시간 전송됩니다. 가족의 음성과 그림(동그라미·선)은 부모님 휴대폰으로 전송됩니다.
  • 이 영상·음성·그림은 기기 사이에서 암호화되어 전송되고, 회사 서버에 저장되거나 녹화되지 않습니다. 연결이 어려울 때는 중계 서버(Cloudflare)를 거치지만, 암호화된 상태 그대로 전달만 됩니다.
  • 화면에 다른 사람의 메시지 등이 보일 수 있습니다. 보여 주기 전에 확인해 주시고, 언제든 [그만 보여 주기]로 멈출 수 있습니다.
  • 연결 정보(접속 제안·응답 문자열)는 연결을 맺는 동안만 서버에 머물고, 가져가는 즉시 지워집니다.

3. 제3자 제공

회사는 개인정보를 제3자에게 제공하지 않습니다. 다만 이용자가 연결을 승인한 가족에게는 이름과 도움 요청이 전달됩니다.

4. 처리 위탁과 국외 이전

받는 자위탁 업무이전 국가항목방법·시기
Google LLC (Firebase: Cloud Functions, Firestore, Cloud Messaging)서버 운영, 기록 보관, 알림 전송대한민국(서울 리전)·미국1항의 항목앱을 쓸 때 네트워크로
Cloudflare, Inc. (Realtime TURN)직접 연결이 안 될 때 암호화된 영상·음성 중계미국 등 Cloudflare 네트워크암호화된 영상·음성(저장 안 함)도움 연결 중에만

5. 이용자의 권리

  • 앱 [설정 → 모든 기록 지우기]로 기기 정보, 가족 연결, 도움 기록을 즉시 지울 수 있습니다.
  • 연결은 [설정 → 연결 끊기]로 언제든 끊을 수 있습니다.
  • 그 밖의 열람·정정·삭제·처리정지 요청은 아래 연락처로 해 주세요.

6. 만 14세 미만

앱은 만 14세 미만을 대상으로 하지 않습니다.

7. 안전성 확보 조치

기기별 비밀값은 해시로만 저장하고, 서버 데이터베이스는 앱에서 직접 접근할 수 없게 막아 둡니다. 전송은 모두 암호화(HTTPS, DTLS-SRTP)됩니다.
